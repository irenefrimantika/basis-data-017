## Lingkup Layanan

Perpustakaan Cendekia IF merupakan organisasi fiktif yang menyediakan layanan
pengelolaan perpustakaan bagi mahasiswa dan masyarakat. Sistem ini digunakan
untuk mengelola data anggota, katalog buku, peminjaman, pengembalian, serta
denda. Basis data dibuat untuk membantu proses pengelolaan data perpustakaan
agar lebih terstruktur, mudah dicari, dan dapat digunakan secara efektif.

## Tujuan Proyek

Membangun basis data perpustakaan yang dapat mengelola data anggota,
buku, peminjaman, pengembalian, dan denda secara terstruktur menggunakan
MariaDB.
